Did Today is a daily accountability tool people actually keep using, because it's built to celebrate real progress instead of tracking who fell behind.
Refined inside Studio Strong, a personal training studio in O'Fallon, IL, against real people and real mornings — not a spec sheet. The same system works for any organization that wants the same thing for its own people.
The idea, in one line
The question it answers is never "did you check in today" — it's "look how much you're actually doing."
Three things done consistently beats eight things done once.

Most tracking tools quietly turn into a to-do list someone starts dreading. Did Today is built the opposite way: a short list — three dids or fewer, on purpose — that's easy to actually keep up with, and a running record of what someone's really accomplished.

Consistency goals aren't open-ended either. They're sized to be provably real (enough real days to call it a habit, not a lucky week), and once one's met, it gets logged as a genuine win before rolling into another short, achievable goal — not a bigger mountain.

No judgment, no lectures, no grading against a long list. Just an honest, running record.

How it actually works
01

One link, no app

Each person gets a single link. They tap it like a bookmark once a day — no download, no account to manage.

02

Whoever's running it sets the plan

A few dids, a schedule, an optional goal. Takes minutes, and it's exactly as much structure as that person needs — no more.

03

Updates come to whoever's leading it

A Sunday email celebrates who had a real week. A daily one, if they want it, flags exactly what needs attention — kept deliberately separate, so neither one waters down the other.
